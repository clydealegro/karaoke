# MacVault Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS menu bar password manager that stores logins in the login Keychain and copies usernames/passwords in one click.

**Architecture:** One Swift package in `macvault/` with a `MacVaultCore` library (model, Keychain store, password generator, search, clipboard and auth-grace logic — all unit tested behind small protocols) and a `MacVault` executable (AppKit status item + `NSPopover` hosting SwiftUI views, Carbon global hotkey, LocalAuthentication prompt). `build.sh` turns the release binary into an ad-hoc signed `MacVault.app`.

**Tech Stack:** Swift 5.9 (tools version), macOS 13+, SwiftUI, AppKit, Security (Keychain), LocalAuthentication, Carbon (hotkey), XCTest.

**Where commands run:** All `swift` / `./build.sh` commands run on the Mac (Terminal, inside `macvault/`). Running `swift test` needs Xcode installed (Command Line Tools alone lack XCTest); `swift build` works with either.

**Code blocks:** Every code block tagged `path=...` is the complete content of that file.

```swift path=macvault/Sources/MacVaultCore/Login.swift
import Foundation

/// A saved login. The password is never held here; stores fetch it on demand.
public struct Login: Identifiable, Equatable, Codable {
    public var id: UUID
    public var title: String
    public var username: String
    public var website: String
    public var updatedAt: Date

    public init(
        id: UUID = UUID(),
        title: String,
        username: String = "",
        website: String = "",
        updatedAt: Date = Date()
    ) {
        self.id = id
        self.title = title
        self.username = username
        self.website = website
        self.updatedAt = updatedAt
    }
}

extension Array where Element == Login {
    /// Alphabetical by title, ignoring case; ties broken by id so order is stable.
    public func sortedByTitle() -> [Login] {
        sorted { lhs, rhs in
            switch lhs.title.localizedCaseInsensitiveCompare(rhs.title) {
            case .orderedAscending: return true
            case .orderedDescending: return false
            case .orderedSame: return lhs.id.uuidString < rhs.id.uuidString
            }
        }
    }
}
```

```swift path=macvault/Sources/MacVaultCore/LoginFilter.swift
import Foundation

public enum LoginFilter {
    /// Logins matching `query` in title, username or website (case- and
    /// accent-insensitive). Title-prefix matches come first, then the rest;
    /// each group is sorted by title. An empty query returns everything.
    public static func filter(_ logins: [Login], query: String) -> [Login] {
        let sorted = logins.sortedByTitle()
        let needle = query.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !needle.isEmpty else { return sorted }

        let options: String.CompareOptions = [.caseInsensitive, .diacriticInsensitive]
        func contains(_ haystack: String) -> Bool {
            haystack.range(of: needle, options: options) != nil
        }

        let prefixMatches = sorted.filter {
            $0.title.range(of: needle, options: options.union(.anchored)) != nil
        }
        let prefixIDs = Set(prefixMatches.map(\.id))
        let otherMatches = sorted.filter { login in
            !prefixIDs.contains(login.id)
                && (contains(login.title) || contains(login.username) || contains(login.website))
        }
        return prefixMatches + otherMatches
    }
}
```

```swift path=macvault/Sources/MacVaultCore/PasswordGenerator.swift
import Foundation

public struct PasswordOptions: Equatable {
    public static let lengthRange = 8...64
    public static let `default` = PasswordOptions()

    public var length: Int
    public var includeDigits: Bool
    public var includeSymbols: Bool

    public init(length: Int = 20, includeDigits: Bool = true, includeSymbols: Bool = true) {
        self.length = length
        self.includeDigits = includeDigits
        self.includeSymbols = includeSymbols
    }
}

public enum PasswordGenerator {
    // Look-alikes 0 O 1 l I are left out so passwords are easy to read and type.
    public static let lowercase = Array("abcdefghijkmnopqrstuvwxyz")
    public static let uppercase = Array("ABCDEFGHJKLMNPQRSTUVWXYZ")
    public static let digits = Array("23456789")
    public static let symbols = Array("!@#$%^&*-_=+?")

    /// Uses the system CSPRNG (`SystemRandomNumberGenerator`).
    public static func generate(_ options: PasswordOptions = .default) -> String {
        var rng = SystemRandomNumberGenerator()
        return generate(options, using: &rng)
    }

    /// Always contains at least one character from every enabled class.
    public static func generate<R: RandomNumberGenerator>(
        _ options: PasswordOptions,
        using rng: inout R
    ) -> String {
        let length = min(max(options.length, PasswordOptions.lengthRange.lowerBound),
                         PasswordOptions.lengthRange.upperBound)
        var classes = [lowercase, uppercase]
        if options.includeDigits { classes.append(digits) }
        if options.includeSymbols { classes.append(symbols) }

        var characters = classes.map { $0.randomElement(using: &rng)! }
        let pool = classes.flatMap { $0 }
        while characters.count < length {
            characters.append(pool.randomElement(using: &rng)!)
        }
        characters.shuffle(using: &rng)
        return String(characters)
    }
}
```

```swift path=macvault/Sources/MacVaultCore/LoginStore.swift
import Foundation

public enum LoginStoreError: Error, Equatable, LocalizedError {
    case notFound
    case invalidInput(String)
    case keychain(status: Int32, message: String)

    public var errorDescription: String? {
        switch self {
        case .notFound: return "That login no longer exists."
        case .invalidInput(let message): return message
        case .keychain(_, let message): return "Keychain error: \(message)"
        }
    }
}

public protocol LoginStore: AnyObject {
    /// All logins, sorted by title. Never touches passwords.
    func list() throws -> [Login]
    func password(for id: UUID) throws -> String
    /// Inserts or updates. `password == nil` keeps the existing password.
    func save(_ login: Login, password: String?) throws
    func delete(id: UUID) throws
}

enum LoginValidation {
    static let emptyPassword = LoginStoreError.invalidInput("Password can't be empty.")

    static func check(_ login: Login, password: String?) throws {
        if login.title.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty {
            throw LoginStoreError.invalidInput("Name can't be empty.")
        }
        if let password, password.isEmpty {
            throw emptyPassword
        }
    }
}

/// Store for tests and SwiftUI previews.
public final class InMemoryLoginStore: LoginStore {
    private var entries: [UUID: (login: Login, password: String)] = [:]

    public init() {}

    public func list() throws -> [Login] {
        entries.values.map(\.login).sortedByTitle()
    }

    public func password(for id: UUID) throws -> String {
        guard let entry = entries[id] else { throw LoginStoreError.notFound }
        return entry.password
    }

    public func save(_ login: Login, password: String?) throws {
        try LoginValidation.check(login, password: password)
        if let password {
            entries[login.id] = (login, password)
        } else if let existing = entries[login.id] {
            entries[login.id] = (login, existing.password)
        } else {
            throw LoginValidation.emptyPassword
        }
    }

    public func delete(id: UUID) throws {
        guard entries.removeValue(forKey: id) != nil else { throw LoginStoreError.notFound }
    }
}
```

```swift path=macvault/Sources/MacVaultCore/KeychainLoginStore.swift
#if canImport(Security)
import Foundation
import Security

/// Stores each login as one generic-password item in the login keychain.
/// Metadata lives in item attributes so `list()` never reads a password.
public final class KeychainLoginStore: LoginStore {
    public let service: String
    private let encoder = JSONEncoder()
    private let decoder = JSONDecoder()

    public init(service: String = "MacVault") {
        self.service = service
    }

    public func list() throws -> [Login] {
        var query = baseQuery()
        query[kSecMatchLimit as String] = kSecMatchLimitAll
        query[kSecReturnAttributes as String] = true

        var result: CFTypeRef?
        let status = SecItemCopyMatching(query as CFDictionary, &result)
        if status == errSecItemNotFound { return [] }
        try check(status)

        let items = result as? [[String: Any]] ?? []
        return items.compactMap(login(from:)).sortedByTitle()
    }

    public func password(for id: UUID) throws -> String {
        var query = itemQuery(id)
        query[kSecMatchLimit as String] = kSecMatchLimitOne
        query[kSecReturnData as String] = true

        var result: CFTypeRef?
        let status = SecItemCopyMatching(query as CFDictionary, &result)
        if status == errSecItemNotFound { throw LoginStoreError.notFound }
        try check(status)

        guard let data = result as? Data, let password = String(data: data, encoding: .utf8) else {
            throw LoginStoreError.keychain(status: errSecDecode, message: "The saved password can't be read.")
        }
        return password
    }

    public func save(_ login: Login, password: String?) throws {
        try LoginValidation.check(login, password: password)

        var attributes: [String: Any] = [
            kSecAttrLabel as String: "MacVault: \(login.title)",
            kSecAttrDescription as String: "MacVault login",
            kSecAttrGeneric as String: try encoder.encode(login),
        ]
        if let password {
            attributes[kSecValueData as String] = Data(password.utf8)
        }

        let query = itemQuery(login.id)
        let status = SecItemUpdate(query as CFDictionary, attributes as CFDictionary)
        if status == errSecItemNotFound {
            guard password != nil else { throw LoginValidation.emptyPassword }
            let add = query.merging(attributes) { _, new in new }
            try check(SecItemAdd(add as CFDictionary, nil))
        } else {
            try check(status)
        }
    }

    public func delete(id: UUID) throws {
        let status = SecItemDelete(itemQuery(id) as CFDictionary)
        if status == errSecItemNotFound { throw LoginStoreError.notFound }
        try check(status)
    }

    // MARK: - Helpers

    private func baseQuery() -> [String: Any] {
        [
            kSecClass as String: kSecClassGenericPassword,
            kSecAttrService as String: service,
        ]
    }

    private func itemQuery(_ id: UUID) -> [String: Any] {
        var query = baseQuery()
        query[kSecAttrAccount as String] = id.uuidString
        return query
    }

    /// Items whose metadata can't be decoded are still listed (titled with
    /// their id) so the user can open and delete them.
    private func login(from attributes: [String: Any]) -> Login? {
        guard let account = attributes[kSecAttrAccount as String] as? String,
              let id = UUID(uuidString: account) else { return nil }
        if let data = attributes[kSecAttrGeneric as String] as? Data,
           var login = try? decoder.decode(Login.self, from: data) {
            login.id = id
            return login
        }
        return Login(id: id, title: account)
    }

    private func check(_ status: OSStatus) throws {
        guard status != errSecSuccess else { return }
        let message = SecCopyErrorMessageString(status, nil) as String? ?? "OSStatus \(status)"
        throw LoginStoreError.keychain(status: status, message: message)
    }
}
```

```swift path=macvault/Sources/MacVaultCore/ClipboardGuard.swift
import Foundation

public protocol Pasteboard: AnyObject {
    var changeCount: Int { get }
    /// Replaces the contents and returns the new change count. `concealed`
    /// marks the item so clipboard-history apps skip it.
    func write(_ string: String, concealed: Bool) -> Int
    func clear()
}

public protocol Scheduler {
    func schedule(after seconds: TimeInterval, _ action: @escaping () -> Void)
}

public struct DispatchScheduler: Scheduler {
    public init() {}

    public func schedule(after seconds: TimeInterval, _ action: @escaping () -> Void) {
        DispatchQueue.main.asyncAfter(deadline: .now() + seconds, execute: action)
    }
}

public final class ClipboardGuard {
    public static let defaultClearDelay: TimeInterval = 30

    private let pasteboard: Pasteboard
    private let scheduler: Scheduler

    public init(pasteboard: Pasteboard, scheduler: Scheduler) {
        self.pasteboard = pasteboard
        self.scheduler = scheduler
    }

    /// Copies `string`. With a delay, the item is concealed and cleared after
    /// the delay unless something else has been copied in the meantime.
    public func copy(_ string: String, clearAfter delay: TimeInterval?) {
        let pasteboard = self.pasteboard
        let changeCount = pasteboard.write(string, concealed: delay != nil)
        guard let delay else { return }
        scheduler.schedule(after: delay) {
            if pasteboard.changeCount == changeCount {
                pasteboard.clear()
            }
        }
    }
}
```

```swift path=macvault/Sources/MacVaultCore/AuthGate.swift
import Foundation

/// Asks the person at the Mac to prove they're the owner (Touch ID or password).
@MainActor
public protocol Authenticator: AnyObject {
    /// `reason` completes the sentence "MacVault is trying to …".
    func authenticate(reason: String) async -> Bool
}

/// Remembers a successful authentication for `gracePeriod` seconds so the
/// user isn't prompted on every copy.
@MainActor
public final class AuthGate {
    private let authenticator: Authenticator
    private let gracePeriod: TimeInterval
    private let now: () -> Date
    private var lastSuccess: Date?

    public init(
        authenticator: Authenticator,
        gracePeriod: TimeInterval = 300, // 5 minutes
        now: @escaping () -> Date = { Date() }
    ) {
        self.authenticator = authenticator
        self.gracePeriod = gracePeriod
        self.now = now
    }

    public func needsAuthentication() -> Bool {
        guard let lastSuccess else { return true }
        return now().timeIntervalSince(lastSuccess) > gracePeriod
    }

    public func ensureAuthenticated(reason: String) async -> Bool {
        if !needsAuthentication() { return true }
        let allowed = await authenticator.authenticate(reason: reason)
        if allowed { lastSuccess = now() }
        return allowed
    }

    public func lock() {
        lastSuccess = nil
    }
}
```

```swift path=macvault/Sources/MacVault/VaultViewModel.swift
@MainActor
final class VaultViewModel: ObservableObject {
    enum Screen: Equatable {
        case list
        /// `nil` means a new login.
        case edit(Login?)
    }

    @Published private(set) var logins: [Login] = []
    @Published var query = ""

    @Published private(set) var flash: String?

    var onCopiedPassword: () -> Void = {}

    private let store: LoginStore
    private let gate: AuthGate
    private let clipboard: ClipboardGuard
    private var flashTask: Task<Void, Never>?

    init(store: LoginStore, gate: AuthGate, clipboard: ClipboardGuard) {
        self.store = store
        self.gate = gate
        self.clipboard = clipboard
    }

    var filteredLogins: [Login] {
        LoginFilter.filter(logins, query: query)
    }

    func prepareForShow() {
        query = ""
        screen = .list
        reload()
        focusToken += 1
    }

    func reload() {
        do {
            logins = try store.list()
        } catch {
            banner = error.localizedDescription
        }
    }

    func copyUsername(_ login: Login) {
        clipboard.copy(login.username, clearAfter: nil)
        showFlash("Username copied")
    }

    func copyPassword(_ login: Login) async {
        guard await gate.ensureAuthenticated(reason: "copy the password for “\(login.title)”") else {
            return
        }
        do {
            let password = try store.password(for: login.id)
            clipboard.copy(password, clearAfter: ClipboardGuard.defaultClearDelay)
            showFlash("Password copied · clears in \(Int(ClipboardGuard.defaultClearDelay))s")
            try? await Task.sleep(nanoseconds: 600_000_000)
            onCopiedPassword()
        } catch {
            banner = error.localizedDescription
        }
    }

    /// Return in the search field copies the password of the top match.
    func copyTopMatchPassword() async {
        guard let first = filteredLogins.first else { return }
        await copyPassword(first)
    }

    func revealPassword(for login: Login) async -> String? {
        guard await gate.ensureAuthenticated(reason: "show the password for “\(login.title)”") else {
            return nil
        }
        do {
            return try store.password(for: login.id)
        } catch {
            banner = error.localizedDescription
            return nil
        }
    }

    func save(_ login: Login, password: String?) {
        do {
            try store.save(login, password: password)
            banner = nil
            reload()
            screen = .list
        } catch {
            banner = error.localizedDescription
        }
    }

    func delete(_ login: Login) {
        do {
            try store.delete(id: login.id)
            banner = nil
            reload()
            screen = .list
        } catch {
            banner = error.localizedDescription
        }
    }

    private func showFlash(_ text: String) {
        flash = text
        flashTask?.cancel()
        flashTask = Task { [weak self] in
            try? await Task.sleep(nanoseconds: 2_000_000_000)
            guard !Task.isCancelled else { return }
            self?.flash = nil
        }
    }
```

```swift path=macvault/Sources/MacVault/LoginEditor.swift
struct LoginEditor: View {
    @ObservedObject var model: VaultViewModel
    let original: Login?

    @State private var title: String
    @State private var username: String
    @State private var website: String
    /// Empty while editing means "keep the saved password".
    @State private var password = ""
    @State private var showPassword: Bool
    @State private var options = PasswordOptions.default
    @State private var confirmDelete = false

    init(model: VaultViewModel, original: Login?) {
        _model = ObservedObject(wrappedValue: model)
        self.original = original
        _title = State(initialValue: original?.title ?? "")
        _username = State(initialValue: original?.username ?? "")
        _website = State(initialValue: original?.website ?? "")
        _showPassword = State(initialValue: original == nil)
    }

    private var isNew: Bool { original == nil }

    private var canSave: Bool {
        !title.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty
            && (!isNew || !password.isEmpty)
    }

    private var lengthBinding: Binding<Double> {
        Binding(
            get: { Double(options.length) },
            set: { options.length = Int($0) }
        )
    }

    var body: some View {
        VStack(spacing: 0) {

                Spacer()
                Button("Save", action: save)
                    .keyboardShortcut(.defaultAction)
                    .disabled(!canSave)
            }
            .padding(10)

            Divider()

            Form {
                Section {
                    TextField("Name", text: $title)
                    TextField("Username", text: $username)
                    HStack {
                        if showPassword {
                            TextField("Password", text: $password,
                                      prompt: Text(isNew ? "" : "Unchanged"))
                                .font(.body.monospaced())
                        } else {
                            SecureField("Password", text: $password,
                                        prompt: Text(isNew ? "" : "Unchanged"))
                        }
                        Button {
                            Task { await toggleReveal() }
                        } label: {
                            Image(systemName: showPassword ? "eye.slash" : "eye")
                        }
                        .buttonStyle(.borderless)
                        .help(showPassword ? "Hide password" : "Show password")
                    }
                    TextField("Website", text: $website)
                }

                Section("Generator") {
                    HStack {
                        Slider(value: lengthBinding,
                               in: Double(PasswordOptions.lengthRange.lowerBound)...Double(PasswordOptions.lengthRange.upperBound),
                               step: 1)

                            .monospacedDigit()
                            .frame(width: 24, alignment: .trailing)
                    }
                    HStack {
                        Toggle("Digits", isOn: $options.includeDigits)
                        Toggle("Symbols", isOn: $options.includeSymbols)
                        Spacer()
                        Button("Generate") {
                            password = PasswordGenerator.generate(options)
                            showPassword = true
                        }
                    }
                }

                if let original {
                    Section {
                        Button("Delete Login", role: .destructive) { confirmDelete = true }

                                Text("It will be removed from your Keychain.")

                }

            .formStyle(.grouped)
        }
    }

    private func toggleReveal() async {
        if showPassword {
            showPassword = false
            return
        }
        // New logins, or a password the user already typed: nothing secret to fetch.
        guard let original, password.isEmpty else {
            showPassword = true
            return
        }
        if let saved = await model.revealPassword(for: original) {
            password = saved
            showPassword = true
        }
    }

    private func save() {
        guard canSave else { return }
        var login = original ?? Login(title: "")
        login.title = title.trimmingCharacters(in: .whitespacesAndNewlines)
        login.username = username.trimmingCharacters(in: .whitespacesAndNewlines)
        login.website = website.trimmingCharacters(in: .whitespacesAndNewlines)
        login.updatedAt = Date()
        model.save(login, password: password.isEmpty ? nil : password)
    }
```

```swift path=macvault/Sources/MacVault/SystemServices.swift
import AppKit
import LocalAuthentication
import MacVaultCore

/// `NSPasteboard.general` behind the core `Pasteboard` protocol.
final class SystemPasteboard: Pasteboard {
    private let pasteboard = NSPasteboard.general
    // Conventions from nspasteboard.org honoured by clipboard managers.
    private let concealedType = NSPasteboard.PasteboardType("org.nspasteboard.ConcealedType")
    private let transientType = NSPasteboard.PasteboardType("org.nspasteboard.TransientType")

    var changeCount: Int { pasteboard.changeCount }

    func write(_ string: String, concealed: Bool) -> Int {
        pasteboard.clearContents()
        let item = NSPasteboardItem()
        item.setString(string, forType: .string)
        if concealed {
            item.setString("", forType: concealedType)
            item.setString("", forType: transientType)
        }
        pasteboard.writeObjects([item])
        return pasteboard.changeCount
    }

    func clear() {
        pasteboard.clearContents()
    }
}

/// Touch ID when available, otherwise the Mac login password.
@MainActor
final class DeviceAuthenticator: Authenticator {
    func authenticate(reason: String) async -> Bool {
        let context = LAContext()
        var error: NSError?
        guard context.canEvaluatePolicy(.deviceOwnerAuthentication, error: &error) else {
            // A Mac account with no login password has nothing to check against.
            return error?.code == LAError.Code.passcodeNotSet.rawValue
        }
        do {
            return try await context.evaluatePolicy(.deviceOwnerAuthentication, localizedReason: reason)
        } catch {
            return false
        }
    }
}
```

```swift path=macvault/Sources/MacVault/HotKey.swift
import Carbon.HIToolbox

/// A system-wide keyboard shortcut via Carbon's RegisterEventHotKey.
/// Unlike an NSEvent global monitor, it needs no Accessibility permission.
final class HotKey {
    private var hotKeyRef: EventHotKeyRef?
    private var handlerRef: EventHandlerRef?
    private let action: () -> Void

    /// Returns nil if the shortcut is already taken by another app.
    init?(keyCode: UInt32, modifiers: UInt32, action: @escaping () -> Void) {
        self.action = action

        var eventType = EventTypeSpec(
            eventClass: OSType(kEventClassKeyboard),
            eventKind: UInt32(kEventHotKeyPressed)
        )
        let userData = Unmanaged.passUnretained(self).toOpaque()
        let installStatus = InstallEventHandler(
            GetApplicationEventTarget(),
            { _, _, userData in
                guard let userData else { return OSStatus(eventNotHandledErr) }
                Unmanaged<HotKey>.fromOpaque(userData).takeUnretainedValue().action()
                return OSStatus(noErr)
            },
            1,
            &eventType,
            userData,
            &handlerRef
        )
        guard installStatus == OSStatus(noErr) else { return nil }

        let hotKeyID = EventHotKeyID(signature: OSType(0x4D56_4C54), id: 1) // "MVLT"
        let registerStatus = RegisterEventHotKey(
            keyCode, modifiers, hotKeyID, GetApplicationEventTarget(), 0, &hotKeyRef
        )
        guard registerStatus == OSStatus(noErr) else { return nil }
    }

    deinit {
        if let hotKeyRef { UnregisterEventHotKey(hotKeyRef) }
        if let handlerRef { RemoveEventHandler(handlerRef) }
    }
}
```

```swift path=macvault/Sources/MacVault/AppDelegate.swift
import AppKit
import Carbon.HIToolbox
import MacVaultCore
import SwiftUI

@MainActor
final class AppDelegate: NSObject, NSApplicationDelegate {
    private var statusItem: NSStatusItem?
    private let popover = NSPopover()
    private var hotKey: HotKey?
    private var model: VaultViewModel?

    func applicationDidFinishLaunching(_ notification: Notification) {
        let model = VaultViewModel(
            store: KeychainLoginStore(),
            gate: AuthGate(authenticator: DeviceAuthenticator()),
            clipboard: ClipboardGuard(pasteboard: SystemPasteboard(), scheduler: DispatchScheduler())
        )
        model.onCopiedPassword = { [weak self] in self?.closePopover() }
        self.model = model

        popover.behavior = .transient
        popover.contentSize = NSSize(width: 360, height: 440)
        popover.contentViewController = NSHostingController(rootView: VaultView(model: model))

        let item = NSStatusBar.system.statusItem(withLength: NSStatusItem.squareLength)
        if let button = item.button {
            button.image = NSImage(systemSymbolName: "key.fill", accessibilityDescription: "MacVault")
            button.target = self
            button.action = #selector(togglePopover(_:))
        }
        statusItem = item

        hotKey = HotKey(keyCode: UInt32(kVK_ANSI_P), modifiers: UInt32(optionKey | cmdKey)) { [weak self] in
            self?.togglePopover(nil)
        }
        if hotKey == nil {
            NSLog("MacVault: ⌥⌘P is already used by another app; the shortcut is disabled.")
        }
    }

    @objc private func togglePopover(_ sender: Any?) {
        if popover.isShown {
            closePopover()
        } else {
            showPopover()
        }
    }

    private func showPopover() {
        guard let button = statusItem?.button else { return }
        model?.prepareForShow()
        if #available(macOS 14.0, *) {
            NSApp.activate()
        } else {
            NSApp.activate(ignoringOtherApps: true)
        }
        popover.show(relativeTo: button.bounds, of: button, preferredEdge: .minY)
        popover.contentViewController?.view.window?.makeKey()
    }

    private func closePopover() {
        popover.performClose(nil)
    }
}
```

```bash path=macvault/build.sh
#!/usr/bin/env bash
# Builds MacVault.app into ./build (run on the Mac, from anywhere).
set -euo pipefail
cd "$(dirname "$0")"

swift build -c release
BIN_DIR="$(swift build -c release --show-bin-path)"

APP="build/MacVault.app"
rm -rf "$APP"
mkdir -p "$APP/Contents/MacOS" "$APP/Contents/Resources"
cp "$BIN_DIR/MacVault" "$APP/Contents/MacOS/MacVault"
cp Resources/Info.plist "$APP/Contents/Info.plist"

# Ad-hoc signature: no Apple developer account needed.
codesign --force --sign - --identifier local.macvault.app "$APP"

echo "Built $(pwd)/$APP"
echo "Install with:  cp -R \"$(pwd)/$APP\" /Applications/ && open /Applications/MacVault.app"
```

````markdown path=macvault/README.md
# MacVault

A small menu bar password manager for macOS. Logins are stored in your
macOS login Keychain; copying a password asks for Touch ID or your Mac
password (then not again for 5 minutes), and copied passwords are wiped
from the clipboard after 30 seconds.

## Requirements

- macOS 13 Ventura or later (Apple silicon or Intel).
- Xcode from the App Store (recommended), or at least the Command Line
  Tools: `xcode-select --install`. Running the tests needs full Xcode.

## Build and install

```bash
cd macvault
./build.sh
cp -R build/MacVault.app /Applications/
open /Applications/MacVault.app
```

A key icon appears in the menu bar. There's no Dock icon.

**Start at login:** System Settings → General → Login Items → **+** → choose
MacVault in Applications.

**First launch:** macOS may say the app is from an unidentified developer.
Right-click MacVault in Applications → **Open** → **Open**. You only do this
once.

## Using it

| Action | How |
| --- | --- |
| Open | Click the key icon, or press **⌥⌘P** anywhere |
| Find | Start typing; matches name, username and website |
| Copy password | Key button on a row, or **Return** for the top match |
| Copy username | Person button on a row |
| Add | **+** next to the search field |
| Edit / delete | Pencil button on a row |
| Generate password | In the add/edit form: pick length, digits, symbols, then **Generate** |

### Keychain prompts after rebuilding

The app is signed ad-hoc, so each rebuild looks like a "new" app to the
Keychain. The first time a rebuilt MacVault reads a password, macOS asks
"MacVault wants to use your confidential information stored in … keychain".
Enter your Mac password and click **Always Allow**.

### Where the data lives

Keychain Access → login keychain → items named `MacVault: <name>` (kind
"MacVault login"). Back them up with the rest of your Mac (Time Machine
includes the login keychain). Deleting an item there deletes it from MacVault.
````
